# 📚 Курсовая работа по БД: Card Management System

## 📁 Структура проекта

```
project/
├── README.md                           # Этот файл
├── 01-introduction.md                  # Введение и назначение системы
├── 02-functional-requirements.md       # Функциональные требования
├── 03-non-functional-requirements.md   # Нефункциональные требования
├── 04-database-schema.md               # Предварительная схема БД (ER-диаграмма)
├── 05-constraints.md                   # Текстовые ограничения на данные
├── 06-dependencies.md                  # Функциональные и многозначные зависимости
├── 07-normalization.md                 # Нормализация схемы БД
├── 08-denormalization-example.md       # Пример аномалии в недонормализованной схеме
├── 09-ddl-script.sql                   # SQL DDL скрипт создания БД
├── 10-dml-queries.sql                  # SQL DML запросы
├── 11-transactions.sql                 # Транзакции
└── 12-conclusion.md                    # Заключение и выводы
```

## 🎯 Цель работы

Разработка реляционной базы данных для системы управления банковскими картами с полным циклом проектирования:
- Анализ требований
- Проектирование схемы БД
- Нормализация до 4НФ
- Реализация на SQL
